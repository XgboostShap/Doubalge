Doubalge

Préparer, corriger et partager une scène de doublage improvisé.

Les projets conservent leurs corrections sur le PC. Pour une ancienne scène, importe son éditeur puis son dernier JSON corrigé dans l’éditeur. Le spectacle reste un export autonome.

Préparer une nouvelle scène

Colle une URL YouTube, ou choisis une vidéo déjà présente sur le PC.

Un sous-dossier distinct sera créé automatiquement. Avec une URL, la vidéo sera téléchargée directement. Un JSON corrigé est réutilisé sans réanalyse IA.
