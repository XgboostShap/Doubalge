    Deux écrans pour le spectacle

    Sur Windows, utilise Win + P → Étendre. Clique sur Ouvrir l’écran public, déplace cette nouvelle fenêtre sur le deuxième écran, puis clique sur son bouton Plein écran. Un double-clic dans cette fenêtre permet aussi de changer le plein écran.

    L’écran public reçoit uniquement la vidéo, sans noms, repères ni réglages. Le son est produit une seule fois par cette fenêtre de commande sur la sortie audio par défaut du PC. La vidéo de l’écran public reste muette pour éviter un écho. Choisis la sortie de la sono dans les réglages audio Windows.

    Prépare chaque scène dans l’éditeur, puis exporte son lecteur impro. Ajoute ces fichiers dans l’ordre du spectacle. Tu peux changer l’ordre, les noms des scènes, les voix retirées et les noms des improvisateurs. Enregistre le spectacle pour conserver l’ensemble et le rouvrir hors connexion.

    Espace : lire/pause · N : scène suivante · P : précédente · B : noir et arrêt. Les vignettes anticipent les paroles de 1,5 seconde et les plans de 0,5 seconde. Fais une répétition sur les deux écrans avant le spectacle.
